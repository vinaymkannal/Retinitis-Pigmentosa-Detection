# Retinitis Pigmentosa Detection using Deep Learning

## 📌 Overview

This project uses a deep learning model (ResNet50) to classify retinal images into:

* Retinitis Pigmentosa (RP)
* Normal

## 🚀 Model

* Architecture: ResNet50
* Accuracy: ~95%
* Framework: TensorFlow/Keras

## 📊 Results

* Training Accuracy: ~98%
* Validation Accuracy: ~95%

## 📈 Outputs

* Accuracy Graph
* Confusion Matrix

## ⚠️ Limitations

* Class imbalance observed
